# OmniPost MCP 能力清单

`@omnipost/mcp` 会根据当前版本、账号授权、订阅方案和平台状态暴露工具。客户端连接后应以运行时返回的工具列表和参数 schema 为准；下面是使用层面的能力分组。

## 平台与账号

- 查看 OmniPost 是否在线。
- 查看已连接的平台和账号。
- 查看平台支持的内容类型、必填字段和发布方式。
- 判断账号是否需要重新授权。

## 内容分发

- 将一篇已有内容转换为平台适配版本。
- 预览标题、正文、媒体、标签和链接。
- 创建平台草稿。
- 定时发布或直接发布已确认内容。
- 返回每个平台独立的成功、草稿、待人工操作或失败结果。
- 查询历史发布记录和公开链接。

## AI 内容运营

- 生成文章、短内容、图片、视频和音频素材。
- 根据平台特点改写标题、正文、标签和 CTA。
- 使用品牌知识、账号人设和内容规则生成平台版本。
- 生成小红书种草、抖音脚本、LinkedIn B2B 内容等场景化内容。

## 评论与转化

- 读取评论和互动信号。
- 识别高意向用户和关键词触发场景。
- 生成评论或私信回复草稿。
- 根据授权和规则执行自动回复或转人工。

## 数据与运营

- 汇总曝光、互动、粉丝增长和发布状态。
- 查询平台级或内容级表现。
- 记录任务、失败原因和需要重新登录的平台。
- 支持后续重试、补发和运营复盘。

## 推荐 Agent 编排顺序

```text
检查 OmniPost 状态
  → 查询账号和平台能力
  → 准备内容与平台字段
  → 预览 / 校验
  → 草稿或排期
  → 用户确认后发布
  → 查询结果与数据
```

MCP 的职责是把 Agent 的结构化决策交给 OmniPost 分发层。Agent 负责选题、写作和判断，OmniPost 负责账号状态、平台差异、校验、草稿、发布和结果记录。
