## 海外

X（Twitter）、LinkedIn、Facebook、Instagram、Threads、TikTok、YouTube、Pinterest，以及产品账号中开放的其他国际平台。

## 如何确认实时能力

连接 MCP 后，先让 Agent 查询平台和账号状态，再根据返回的能力字段选择草稿、预览、排期或发布。不要假设所有平台都支持相同的内容类型或自动发布方式。

官方平台覆盖页：[OmniPost AI](https://www.omnipost.cc/en/)。
